# Production brief

## Purpose
What the viewer should feel, understand, and do.

## Source and scope
- Project key, thread, explicit sequence
- Supplied script / approved copy / reference material
- Audience, placement, tone, aspect, target duration
- Required product sources, end cards, exclusions and unresolved claims
- Authorized generation scope, budget and review checkpoints

## Story and coverage
- Premise, emotional engine, pivot, hook variants and shared body
- Stable line IDs, speakers, exact copy and separate spoken text when required
- Cast IDs, fixed identifiers and selected references
- Set IDs, stations, cameras, layout, scale and master references
- Shot IDs, covered lines, framing, action, background and reference roles

## First proof
- Cheapest pilot that tests the uncertain decision
- Concrete criteria to review before scaling
- Current board URL and revision
