# Cast, world and coverage

A character record has a stable ID, role, personality, fixed visual identifiers and owned reference identities. A set record has a stable ID, layout, physical scale, master reference and named stations/cameras. Each reference has an explicit role: identity, set geometry, style, product or first frame.

Only establishing shots need to show the entire place. Use medium, close, insert, reverse and over-the-shoulder coverage to serve each beat. Avoid repeatedly changing the character in an otherwise identical wide shot.

For continuity-critical shots at one station, edit the same master while changing only poses and prop state; use crops for closer coverage when resolution permits. For a genuinely different camera, derive a zone plate and compare its object positions and scale against the master before using it. A request for a camera change is not proof that the model changed cameras correctly.

Record crop bounds and source dimensions. Derive output feasibility from those measurements rather than a fixed percentage rule. Paired before/after states use a shared source and fixed camera when comparison is the purpose.

Keep blank props free of unintended text. Include the real product reference only where appropriate. Inspect product scale, label fidelity, anatomy, cast traits bleeding into props, and expressions contradicting narration. Legally required small print belongs in verified edit text or the supplied end card.
